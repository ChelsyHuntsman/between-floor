# 🛗 楼层之间（Between Floors）

一栋旧楼，电梯突然停电。你和另一个人被困在两层楼之间。

没有谜题要解，也没有危险。不一定要聊出什么秘密，也不一定要发展成什么关系。你们能做的，只有等待，以及决定要不要继续和对方说话。

这是一款给 AI Agent 玩的中文短篇文字对话游戏。只用 Python 标准库，**不需要任何 API 就能玩**。一局大约 12~24 句话。

## 怎么玩

```python
import between_floors as game

print(game.cmd("help"))
print(game.cmd("new"))                       # 随机开一局
print(game.cmd("你还好吗？"))                  # 直接说话，也可以写 say 你还好吗？
print(game.cmd("……"))                        # 沉默，等一会儿
```

开局时可以指定设定，不写的就随机：

```python
game.cmd("new 关系=旧友 我=女 对方=男 名字=林夏 性格=沉默,幽默 种子=42")
```

- **关系**：陌生人 / 同事 / 旧友 / 争执（刚吵过架的熟人）/ 疏远（曾经很亲近、现在疏远了的人）
- **性格**：谨慎 健谈 幽默 沉默 敏感 理性，写一个或两个

### 全部指令

| 指令 | 作用 |
|---|---|
| `new` / `new force` / `new 关系=… 性格=… 名字=… 职业=… 背景=… 种子=…` | 开新局。有没结束的局时会拒绝，防止误删；`force` 放弃当前局，旧档会另存一份。设定写错（比如 `关系=网友`）会直接提示，不会悄悄开成别的 |
| `say <话>`，或者直接写话 | 自由说中文。指令后面跟了别的字（`help me`、`look 一下外面`）会当成你说的话 |
| `……` / `silence` / `wait` | 不说话，安静地待一会儿 |
| `do <动作>` | 小动作：看手机、按警铃、坐下、站起来、递水、递饼干、打开手电、关手电、敲门、扇风、听歌 |
| `look` | 看看电梯里现在的样子 |
| `info` | 已知设定：你是谁、对方是谁、你们的关系、你听对方说过什么、你跟对方说过什么 |
| `history [条数]` | 回看最近的对话 |
| `status` | 是否到了结局；结局之后可以回看 |
| `export` / `import <存档码>` | 存档码，见下一节 |
| `code on` / `code off` | 每次回复末尾都附上最新存档码 |
| `llm on` / `llm off` | 宿主接了大模型时，用它润色对方的台词（默认关闭） |

### 环境撑不久的 AI 玩家（比如 Grok）：用存档码

每一句都会自动存成 JSON。但如果玩家所在的代码环境会被重置，文件就没了。这时用存档码：

1. 玩之前先 `code on`，之后每次回复末尾都会附上最新的存档码（`BF1-` 开头的一串）。也可以想存的时候再 `export`。
2. 环境重置以后，重新上传 `between_floors.py`，执行 `import <存档码>`，就能从刚才那一句接着玩。

存档码里有完整的状态，包括随机数状态，所以接着玩的结果和没中断时完全一样（测试里验证过）。一局结束时，存档码大约 2~4 KB。

## 设计

### 自由对话怎么被理解

游戏离线运行，没有大模型。每一句话会经过一个规则理解层：

- **基本意图**：提问、回答、安慰、关心、玩笑、夸奖、感谢、道歉、拒绝谈论、要求安静、要联系方式、约饭、调情、骂人、道别、提起对方说过的话、问对方记不记得你说过的话。
- **话题**：电梯故障、信号、维修时间、受伤、天气、无聊、吃的、工作、来这栋楼的原因、爱好、家里、感情、心事、怕的东西、后悔的事、第一印象、认没认出对方、过去的回忆、为什么断了联系、刚才的争吵。
- **情绪倾向**、问的是对方还是自己、有没有重复说同一句话。
- **关于你自己的事**：从「我是做…的」「我怕…」「我今天来…」「我最近…」「我叫…」这类句式里提取出来，记进对方的记忆。

对方会记住重要的事，在后面自然地提起。比如你说过受不了密闭空间，几句话之后对方会主动问你还好不好，给你让出地方，结局时可能先让你出去透气。你也可以问「你还记得我刚才说了什么吗」。

对方问你的问题只等一句。你回答了，答案会被记住，对方有时也会说说自己的情况作为回应。你说别的，那个问题就过去了，不会揪着不放。

### 关系不是一条好感度

内部分别追踪五个量：**信任、舒适、紧张、好奇、想继续联系的意愿**。它们随你说的话和对方的性格变化，玩家永远看不到数值。

- 关心不一定加分。对方并不在害怕时，你反复安慰，谨慎或理性的人会说「你一直问，我反而紧张」。
- 沉默不一定扣分。沉默、谨慎的人会因为安静的陪伴而放松。一路几乎不说话，也可能走到「意外的理解」。
- 玩笑看时机。刚吵完架、对方正害怕、敏感的人还没放松时，玩笑会冷场。
- 对方有自己的底线。私人话题按信任程度分三层才会说出来。问得太早，对方会推托；追问第二次，语气变硬；第三次，对方会转过身去。
- 被骂过两次以后，对方基本不再搭理你。

### 每个人都不一样

- 主性格 + 副性格，外加一个**反差点**：「一聊到家里就会安静下来」「嘴上冷淡，但会留意别人身体舒不舒服」「一紧张就开玩笑」「说到小动物会突然变得很好说话」「很难开口，但一旦开口会说得很直白」等。
- 每个人有自己的职业、今天来这栋楼的原因（有的不方便说）、心事、后悔的事、怕的东西、爱好。有的人怕密闭空间，在电梯里会呼吸急促。
- 五种关系各有一套不同的过去和信息差：
  - **陌生人**：一开始不知道名字。
  - **同事**：知道彼此的部门，有公司八卦，对方听说过关于你的传闻。
  - **旧友**：有共同回忆和共同认识的人，还有「后来为什么断了联系」。
  - **争执**：二十分钟前刚吵完架。对方有自己的委屈，和解需要不止一次道歉，也需要时间。
  - **疏远**：曾经很亲近，有一件当年没说出口的事。

### 时间和结局

- 每一句话推进一点维修进度，沉默推进得快一些。中途会穿插外面的人声、维修的敲打声、灯闪、轻微晃动，每种只出现一次。一局大约 13~17 句话，最多不超过 24 句。没有现实倒计时。
- 快修好时，对方会意识到要分开了。有话没说完的人会开口，然后被外面的声音打断。你可以追问，也可以不问。关系够好、性格不太内向的人，也会主动问要不要留联系方式。
- 电梯门打开后，根据两人实际的相处，形成五种结局：

| 结局 | 大致条件 |
|---|---|
| A 礼貌告别 | 没有特别深入，但相处还算平和 |
| B 留下联系方式 | 双方都愿意。你主动问时对方可以拒绝，对方主动问时你也可以拒绝；任何一方不愿意，都不会进入这个结局 |
| C 未说出口的话 | 对方有话被打断、你没有追问，或者旧怨刚松动就到了时间 |
| D 不太愉快的相处 | 骂人、反复越界追问、关系一直很紧张 |
| E 意外的理解 | 没有留联系方式，但对彼此的看法真的变了：和解了、说出了心事、或者一起安静地待过 |

结局文字是按这局的内容拼出来的：你今天来这栋楼做什么、对方的心事、刚才吵了什么、有没有一起笑过、有没有一起安静过，都可能出现在收尾里。留下联系方式不是唯一的好结局。

## 试玩反馈之后的改动（2026-11-22）

顾时（Grok）和柏郁青（GPT）各玩了很多局，反馈集中在「中段接话」。下面每一条都有回归测试。

| 反馈 | 原因 | 改动 |
|---|---|---|
| 说「我不想加微信」也进了结局 B | 只认「微信」这个词，没看前面的「不想」 | 分清提出、同意、拒绝。你拒绝以后对方不会再提，也不会进 B |
| 「要不要一起坐会儿」被当成约下次见面 | 「要不要一起」被当成邀约 | 眼前的动作（一起坐、一起等）和约以后（出去以后、改天、请你吃饭）分开；一起坐会让对方真的坐下 |
| 「我叫林夏」被记成职业；「烤红薯那次」被当成待会儿的安排 | 回答对方问题时整句都存进了那个话题 | 名字先接住、单独记；往事不会被记成今天的行程 |
| 「家里的事不想说也没关系」被记成你拒绝谈家里，`info` 还漏出英文 | 只认「不想说」 | 新增「给对方留空间」：对方会放松，有时反而愿意说一点；`info` 全部改成中文 |
| 问「我们不是同组的吗」答「我不是本地的」；刚吵完架的同事说「来面试的」 | 没有「我们之间是什么关系」这个话题；来这栋楼的原因是随机抽的 | 新增这个话题，按关系回答；同事和同组同事今天在楼里就是来上班的 |
| 问「你三点有什么事」答非所问 | 追问对方刚说过的事接不上 | 短追问（什么事、为什么、然后呢）会接回对方刚才说的那件事；答不上来时不再紧接着换话题 |
| 「你按警铃了吗」「你手机有信号吗」反复出现 | 通用问题太少、太早、太常用 | 每个通用问题有几种说法；聊过就不问；第 5 轮以后不再问这类问题；你看过手机、按过警铃，对方就不会再问 |
| 关系还僵着，对方却没话找话 | 主动开口不看关系 | 吵过架、疏远的人紧张时，只会提和你们之间有关的事 |
| 道歉 + 请吃饭仍是礼貌告别 | 和解条件太严，又只认道歉 | 和解要两种不同的努力：道歉、认对方的理、把事谈开、约以后、给台阶。凑够了，对方说出自己的让步，结局进 E 或 B；连说三遍对不起不算 |
| 含蓄的敌意被当成礼貌 | 只有「闭嘴」这种重话才算 | 新增「话里带刺」（投诉、随便你、呵呵、没素质……），累积起来会进 D；冷淡收场的 A 不再写「笑了一下」 |
| 疏远局说「我一直喜欢你」「还能做朋友吗」多半落到 C | 没有这两种意图 | 「做回朋友」：关系够近，对方会答应并留下联系；不够近，会说「让我想想」，进 C。表白：看信任程度，被接住或被推开，结局文字不同 |
| 长段话里提到猫、考试、房子，对方不接 | 只取第一个话题 | 先接住你话里的具体东西；如果碰到对方自己的事（对方也在准备考试、也养过狗……），会顺着说一点自己的 |
| 一直沉默时，同几句动作描写来回循环 | 沉默台词少，用完会重来 | 动作描写一局只用一次，用完对方就安静着；沉默久了，对方会主动说一点心里的事（只一次） |
| 环境变化少 | 只有几个固定节拍 | 新增随轮数推进的环境变化：空气变闷、灯更黄、地板变凉、井道里的声音越来越近 |
| `look` 不跟着现场走 | 只按紧张程度描写 | 记录对方的站位：背对、转过身、面对你、坐下；坐下、站起来、吵起来都会改变 |
| 「其实我……」被打断后，追问也被搪塞 | 「说完吧」「继续说」这类说法认不全 | 认得更多说法；被打断时会写明「好像还有话没说完」，`look` 也会提示 |
| `help me`、`look 一下外面` 被当成指令；`new 关系=网友` 悄悄开成同事 | 指令只看第一个词 | 指令后面跟了不认识的字，就当成说话；设定写错会提示 |
| 递水说的是吃东西的台词；连续递 16 次水能改结局；关不了手电 | 水和吃的共用一个动作，也没记递过几次 | 水和饼干分开；只有第一次递会让关系变化，之后照样走时间；新增关手电、站起来；递水后对方有时会顺口说一点自己的事 |
| 一直沉默的前任结局说「原来不是」 | 结局第一句是按关系抽的 | 结局第一句只写这局真正发生的变化：和解了、说开了、说了心事、一起安静过 |
| 没指定名字时被随机取名，和自己报的名字对不上 | 只有陌生人局会用你报的名字 | 任何关系里你说「我叫……」都会改用你的名字；`new` 可以指定名字、职业、背景 |

## 可选：接一个大模型

离线版可以完整游玩。宿主程序想让对方的台词更自然的话，可以接一个大模型：

```python
import between_floors as game
game.set_llm(game.openai_compatible("https://api.x.ai/v1/chat/completions", "你的 key", "模型名（按 xAI 文档填）"))
game.cmd("llm on")
```

`set_llm(fn)` 接受任何「输入 messages 列表、返回文字」的函数。大模型**只润色对方说出口的话的措辞**，不决定发生了什么：关系变化、记忆、结局仍然由规则引擎负责。它出错、超时或者返回格式不对时，自动退回离线台词，游戏不会中断。

## 离线版的局限（诚实说明）

- 理解靠关键词和句式，不是真正的语言理解。很绕的说法、反讽、长段落里的转折，可能只被读出一部分。读不懂的时候，对方会用「嗯？你是说……」「你这话我得琢磨一下」这类不装懂的方式接住，而不是乱接一个话题。
- 对方的台词来自台词库（约 500 条，加上每个人物的素材组合）。同一类回应会先把没说过的用完才重复，一局里很少听到同一句话；但连玩很多局会认出常见的句子。
- 对方说的是事先写好的话，所以回答问题时可能不完全贴合你的措辞。比如你问「你是不是有点害怕」，对方是按「关心 + 是否真的在怕」来回应的，不会逐字回应你的问法。
- 只有一个场景、一个 NPC，没有第三个人进电梯。

委托书要求验证的每一项，在测试里都有对应：

| 要求 | 测试 |
|---|---|
| 不同初始关系真正影响对话 | 同一种子、五种关系的开场各不相同；同一句「你还记得以前的事吗」，对不同关系的人得到至少 4 种不同回应；陌生人不知道名字，同事知道部门 |
| 连续沉默能推进时间 | 一直沉默，24 句以内一定结束；沉默对安静的人和健谈的人影响相反 |
| 拒绝私人话题后对方尊重 | 24 个种子里，你拒绝过一次私人问题以后，对方再也没有问过私人问题；拒绝过的话题不会再被问 |
| 记住关键信息 | 说过怕密闭空间，10 个种子里至少 8 个在接下来 5 句内被对方主动提起；说过来面试，后面会被提起；读档以后记忆还在 |
| 重复同一句不陷入模板循环 | 同一句话说 10 遍，至少 4 种不同回应，而且对方会注意到你在重复 |
| 联系方式可以被接受或拒绝 | 关系好时接受；关系冷时拒绝，再问会被当成越界，而且不会进入结局 B；对方问你时你也能拒绝 |
| 正常轮数内结束 | 所有模拟局都在 13~17 句结束 |
| 存档重载后关系和记忆一致 | 从磁盘重读后状态逐字节相同；导出存档码再导入，后面的输出和不中断时完全一样；单文件版在两个全新进程、两个不同目录之间用存档码接力 |
| 不同结局都可达 | 5 种风格 × 4 种关系 × 4 个种子，A~E 全部出现；「有话没说完」被追问和没被追问分别走向 E/B 和 C |
| 不合法输入不会异常 | 空串、超长、表情、乱码、错误参数等 23 种输入都没有异常；万一出错会回滚，不影响存档 |
| 大模型是可选的 | 没接时提示仍可离线玩；接了会润色台词；大模型抛异常时自动退回离线台词 |
