# 🛗 楼层之间 | Between Floors

**一款为 AI 玩家设计的自由对话式文字叙事游戏。**

> 电梯停了。
>
> 你和另一个人，被困在两层楼之间。
>
> 没有谜题需要解开，没有危险需要逃离。
>
> 只是两个原本可能不会交谈的人，突然拥有了一段不得不共同度过的时间。
>
> 你可以说话，可以沉默，可以试着了解对方。
>
> 也可以什么都不做，等待电梯重新启动。
>
> 门总会打开。
>
> 至于在那之前，会发生什么——取决于你们。

---

## 📖 游戏简介

《楼层之间》（Between Floors）是一款以**人物互动、自由对话和关系变化**为核心的短篇文字叙事游戏。

故事发生在一栋旧楼的电梯里。

一次突如其来的停电，让你和另一名乘客困在两层楼之间。在等待维修的过程中，你可以自由地与对方交谈、观察环境、做出动作，或者保持沉默。

对方并不是单纯等待玩家选择的 NPC。

TA 有自己的职业、性格、生活经历、烦恼与不愿轻易谈起的事情。

有些话题能让两个陌生人逐渐熟悉，有些问题却可能让气氛变得更加尴尬。你所说的话、采取的行动以及选择保持沉默的时刻，都可能影响这段短暂的相处。

**游戏没有要求玩家必须完成的社交目标，也不要求每一段相遇都产生深刻的结果。**

电梯修好以后，故事自然结束。

## ✨ 游戏特色

### 💬 自由对话，没有固定选项

游戏不采用传统的 A/B/C 对话菜单。

你可以直接输入任何想说的话：

- 「你还好吗？」
- 「我们是不是以前见过？」
- 「如果你不想说，也没关系。」
- 「说实话，我现在有点紧张。」

也可以选择什么都不说。

游戏会根据当前人物、关系、话题以及对话进展，生成相应的互动。

### 👥 随机人物与初始关系

每次开始游戏，都可能遇到不同的人。

人物拥有不同的职业、性格、经历与心事。

玩家与对方的初始关系包括：

| 关系 | 说明 |
|---|---|
| 陌生人 | 完全不认识的两名乘客 |
| 同事 | 认识但不太熟悉的同事 |
| 旧友 | 很久没有联系的朋友 |
| 争执 | 刚刚发生过争执的熟人 |
| 疏远 | 曾经亲近，如今已经渐行渐远的人 |

人物可能具有谨慎、健谈、幽默、沉默、敏感或理性等性格倾向。

相同的提问，面对不同的人，未必得到相同的回答。

### 🫧 隐藏的关系变化

游戏在后台记录人物之间的互动状态。

对方对你的信任、与你相处时的舒适程度、紧张感、好奇心，以及是否愿意保持联系，都可能随着游戏进程变化。

但这些数值不会以传统好感度面板的形式向玩家公开。

你需要通过对方的语言、行动和态度判断你们的关系。

**一次谈话的意义，不一定能被一个数字概括。**

### 🌙 沉默也是一种选择

你不需要一直寻找话题。

输入 `……`，就可以安静地等待一会儿。

有时沉默意味着尴尬，有时意味着尊重，也可能只是两个人都不知道接下来该说什么。

游戏允许对话自然停顿。

### 🚪 多种相遇与结局

不同的人物、初始关系、对话和行动，可能带来不同的故事走向。

一局通常包含约 **12～24轮互动**。

没有倒计时，也不需要追求所谓的完美结局。

电梯重新启动时，这段相遇便告一段落。

## 🚀 快速开始

### 运行环境

- Python 3
- 无需安装第三方 Python 依赖
- 默认离线运行
- 无需 API Key

下载本项目中的 `between_floors.py`，放入你的 Python 工作目录。

在 Python 环境中运行：

```python
import between_floors as game

# 查看指令
print(game.cmd("help"))

# 开始随机游戏
print(game.cmd("new"))

# 观察电梯
print(game.cmd("look"))

# 与对方交谈
print(game.cmd("你还好吗？"))

# 保持沉默
print(game.cmd("……"))
```

游戏使用统一的 `cmd()` 接口。

每次向 `cmd()` 传入一条指令或一句话，即可获得相应的游戏反馈。

### 自定义开局

如果不想完全随机，可以指定初始关系、人物性格、性别或随机种子：

```python
print(game.cmd(
    "new 关系=旧友 性格=沉默,幽默 我=女 对方=男 种子=42"
))
```

还可以进一步指定人物信息：

```python
print(game.cmd(
    "new 名字=林夏 职业=插画师 背景=刚搬来这个城市"
))
```

所有设定均为可选项。

未指定的内容由游戏随机生成。

如果当前已有未结束的游戏，需要使用 `new force` 才能强制开始新的一局；原存档会另存备份。

## 🎮 常用指令

| 指令 | 功能 |
|---|---|
| `new` | 开始随机游戏 |
| `new force` | 放弃当前游戏并重新开局 |
| `say 你好` | 与对方交谈 |
| `你好` | 直接输入对话，无需添加 `say` |
| `……` | 保持沉默，让时间向前推进 |
| `wait` | 等待一会儿 |
| `do 看手机` | 执行一个动作 |
| `do 递水` | 尝试向对方递水 |
| `do 按警铃` | 按下电梯警铃 |
| `look` | 观察当前环境 |
| `info` | 查看当前已知的人物与关系信息 |
| `history 10` | 回看最近10条对话 |
| `status` | 查看当前游戏状态或结局 |
| `help` | 查看完整指令说明 |

游戏还支持坐下、站起来、打开或关闭手机手电、敲门、听歌等动作。

**注意：** `do` 用来执行动作，普通对话直接输入即可。

游戏也允许你通过对话表达行动或意图，但具体反馈会根据当前状态和指令处理规则决定。

## 💾 存档与恢复

游戏支持自动存档。

默认情况下，存档保存至：

```text
between_floors_save.json
```

每次有效操作后，游戏会自动保存当前进度。

重新加载游戏模块后，可以继续此前未完成的对话。

### 自定义存档位置

```python
game.set_save_path("my_save.json")
```

也可以使用环境变量 `BETWEEN_FLOORS_SAVE` 指定路径。

### 存档码

考虑到部分 AI 运行环境可能中途重置，本游戏还提供可跨会话使用的存档码。

生成存档码：

```python
print(game.cmd("export"))
```

恢复存档：

```python
print(game.cmd("import <存档码>"))
```

也可以启用自动附带存档码的模式：

```python
print(game.cmd("code on"))
```

此后每次游戏回复都会附带最新存档码。

关闭该功能：

```python
print(game.cmd("code off"))
```

建议在不支持长期保存本地文件的 AI 环境中使用此功能，以免游戏进度意外丢失。

## 🤖 给 AI 玩家的说明

本项目专门考虑了 AI Agent 的游玩方式。

你可以将游戏文件提供给支持 Python 执行的 AI，并要求它以玩家身份进行游戏。

推荐提示词：

> 你现在是一名游戏玩家。
>
> 请阅读 `between_floors.py` 顶部的玩家说明，并按照公开接口开始游戏。
>
> 你可以自由决定说什么、做什么、什么时候沉默。
>
> 请根据游戏中的实际反馈作出选择，不要将 NPC 当作需要刷好感度的答题对象。
>
> 请严格遵守盲玩规则，不解码、读取或分析封装的隐藏剧情和结局条件。
>
> 允许你记录对话、观察人物变化，以及对自己的选择进行反思。
>
> 请尽可能自然地体验一次完整的相遇，直到游戏结束。

### 🔒 关于盲玩机制

为了尽可能减少 AI 玩家提前读取剧情的情况，游戏采用了盲玩封装形式。

人物的隐藏信息、部分内部规则及结局条件被封装在 `_BLOB` 中。

这不是安全意义上的加密，而是一种**让 AI 玩家自觉避免提前剧透的游玩约定**。

请不要：

- 解码 `_BLOB` 以读取隐藏内容。
- 直接查看内部人物秘密或结局条件。
- 修改游戏状态来强制触发指定结局。
- 通过源代码分析代替正常游玩。

请通过角色对话、环境观察和实际行动逐渐了解故事。

如果你是开发者、维护者或测试人员，则可以根据需要检查对应的开发版源文件。

## 🧩 关于 AI 与语言模型

《楼层之间》的核心游戏机制可以完全离线运行。

**游戏不依赖在线语言模型来决定人物行为和剧情发展。**

游戏另外提供可选的 `set_llm(fn)` 接口，允许宿主程序接入语言模型，对人物台词进行润色。

默认情况下，该功能关闭，不影响正常游玩。

这也意味着：

- 不需要购买 API 服务即可运行游戏。
- 没有联网条件也可以进行完整体验。
- AI 玩家与游戏 NPC 是两个不同的角色。
- 是否接入语言模型，不改变游戏作为独立文字叙事程序的基本运行方式。

## 💭 设计理念

传统文字冒险往往会告诉玩家：

你必须解开什么谜题，完成什么任务，达成怎样的目标。

但《楼层之间》想讨论的是另一件事。

**如果一段对话没有明确的目的，我们还会不会认真地与陌生人交谈？**

你可能遇见一个急着赶去面试的人，一个不愿谈起过去的旧友，或者一个原本就对你有所不满的熟人。

你可能听到一个故事，也可能什么都没能问出来。

有些人需要安慰，有些人不想被安慰。

有些问题没有标准答案，有些沉默也不必被打破。

这是一款关于短暂相遇的游戏。

它不要求玩家拯救任何人，也不把获得信任视为唯一正确的结果。

你只是在电梯里，和另一个人待了一会儿。

然后门开了。
